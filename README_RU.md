Асинхронный Telegram-бот для автоматизации учета, складского распределения и P2P-продажи цифровых профилей eSIM с интеграцией криптовалютных платежей.

### Архитектурные особенности:
* **Автоматизированный учет инвентаря:** Прием, валидация и безопасное хранение QR-кодов и метаданных операторов связи в реляционной базе данных.
* **Система управления заявками:** Очередь на удержание (hold) и мгновенный выкуп номеров участниками закрытых торговых групп.
* **Финансовый шлюз:** Автоматическая фиксация заявок на вывод средств и интеграция расчетных реквизитов Telegram CryptoBot.
* **Ролевая модель:** Изолированные панели управления для администраторов, поставщиков цифрового товара и покупателей.

### Стек технологий:
* Python 3.12
* Aiogram 3.x (Асинхронный каркас Telegram-бота)
* SQLite / SQLAlchemy (Хранилище транзакций и инвентаря)
* python-dotenv (Конфигурация окружения)
